# 声音、学习纪念章与信纸阅读

## 本地运行

`npm run dev` 同时启动 Vite（127.0.0.1:5173）和本地语音代理（127.0.0.1:4062）。生产镜像由 Node 在 4061 提供网页与语音接口。`npm run preview` 仅预览静态网页；完整声音功能使用开发服务或 Docker。

服务器密钥写入根目录 `.env.local`：`MIMO_API_KEY=你的密钥`。该文件已经被 Git 与 Docker 构建上下文排除。生产部署在 compose 同目录单独配置同名文件，不能放入 public 或使用 VITE_ 环境变量。

## 白桦流式语音

- 官方接口：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5
- 指定端点 `https://token-plan-cn.xiaomimimo.com/v1/chat/completions`，模型 `mimo-v2.5-tts`，音色由 `MIMO_TTS_VOICE` 配置，默认 `白桦`。`MIMO_TTS_PROMPT` 配置演绎提示词，默认留空且不发送 user 风格消息。修改后需重新创建 Docker 容器，或重启本地开发服务。
- 服务端解析 SSE 中的 PCM16 数据，转发 24 kHz 单声道 PCM；浏览器边接收边排程播放，不等待整篇合成完成。
- 8 个模块与 22 个站点的原创解说词在 `src/narration.ts`。详情朗读读取当前可见正文与对比数字，跳过标题区、时间地点、图片说明和阅读提示，跳过按钮、输入框、参考来源、练习区与隐藏内容；可展开内容后重新朗读。
- 长文按语句拆分，每段不超过 500 字；取消、换页或关闭当前朗读弹窗会停止已排程音频并中止请求。
- 所有讲解与诗词朗读共用一条语音声道；背景音乐使用独立播放元素，不会被朗读打断。音量分别保存；详情弹窗内也可打开音量浮窗。
- 8 个模块首页和 22 个全景站点使用无边框麦克风图标。背景音乐播放时，仅对尚未播放过讲解的模块或站点自动讲解。自动或手动成功开始播放后，按页面记录在浏览器 localStorage，再次进入或刷新均不再自动播放，仍可手动重听；加载失败不记为已播放，存储不可用时至少在本次访问内记忆；音乐暂停时不自动触发。悬停地图、改变音量、手动停止或关闭详情不会重启本页讲解。直接打开详情时不自动插入背景页面的解说。
- 服务端限制单次文字长度、4 个并发请求与同一连接地址每分钟 30 次请求。反向代理部署时，请保留 Host，并关闭代理响应缓冲；多人集中使用可按实际额度调整限流。

## 背景音乐

音乐清单为 `public/audio/tracks.json`，音频位于同目录，随网页本地部署。点击顶部音符按钮后播放，不强制自动播放。支持暂停、循环及背景音乐与讲解的独立音量调节。

当前默认曲目为用户提供的《长征交响序曲》，部署文件为 `public/audio/changzheng-overture.mp3`。从原始 320 kbps MP3 压缩为 192 kbps，保留 44.1 kHz 立体声与完整时长（约 7 分 17 秒），未裁剪或调整音量。下载目录中的原文件保持不变。

上一版《山河长路》的音频归档于 `music/exports/`，工程、渲染报告与采样许可记录另见 `docs/music-production.md`。

## 学习勋章

学习中心地图的“足迹与勋章”展示 8 枚原创 SVG 纪念章。完成任意一站、六站、二十二站阅读；读完五则、二十则故事；完成一个、四个不同情境任务；完成十五题测验，分别获得纪念章。单站思考不计作情境任务。旧记录自动补领，获得后持续保存，导出与导入包含勋章。

纹样来自红星、群山、旗帜、马灯、书卷、草鞋、桥梁与麦穗。这些是网站的学习奖励，不是历史实物勋章。

## 详情阅读

共用原生 dialog，采用暖色纸张、浅纸纹与折痕、墨色文字和柔和阴影。保留 Escape 关闭、焦点返回、移动端滚动及降低动态效果设置。朗读按钮位于弹窗右上角。
