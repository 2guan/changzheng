# 八章山河地图改版方案

2026-10-24

## 设计定位
面向历史学习者的沉浸式山河图册。保留朱砂红、暖金、旧纸与全景绘画，统一导航方式，让学习发生在探索途中。设计变化 7 / 动效 4 / 信息密度 3。优先静观、选站、阅读，不设置解锁门槛。

## 信息架构
总地图 → 模块叙事路线 → 全景、完整文章或可选学习活动。

| 模块 | 路线节点 | 进入后的内容 |
| --- | --- | --- |
| 启程首页 | 8 个模块 | 首页开篇及七条专题路线 |
| 历史序幕 | 4 站 | 处境对照、反围剿背景、出发前夕、行囊取舍 |
| 万里征途 | 22 站 | 已有 22 幅宽幅全景；资料地图另保留 |
| 四路红军 | 4 站 | 四支队伍各自的路线、时间与史料 |
| 篝火夜话 | 20 站 | 原有完整故事及 20 件物品图 |
| 长征回响 | 4 站 | 三个比喻、历史价值、历史辨析、个人回望 |
| 诗意长征 | 5 站 | 诗文、白话解读、设备朗读与可选练习 |
| 学习中心 | 6 站 | 足迹、测验、情境任务、笔记、收藏、备份 |

## 共用交互
- 每个模块采用同一个地图组件：全景底图、曲线路径、编号节点、站点预览与进入按钮。
- 点选只更新预览，不强制进入；上一站、下一站、目录适用于全部路线。
- 当前站点存入 URL，返回地图恢复站点；旧全文、军团、诗词、故事、全景链接兼容。
- 阅读页面提供返回当前模块路线和总地图的入口；22 站全景保留现有环顾和文字切换。
- 地图是叙事结构，明确说明不代表真实地理比例；真实地理路线保留在史料视图。
- 移动端可横向查看地图，并提供无需拖动的前后选站与目录。键盘可操作全部节点，保留焦点样式，尊重减少动效偏好。

## 全景素材
使用内置 imagegen 生成 4 幅独立宽幅图，全部保存到 public/assets：
1. atlas-world.webp：山河总览，从赣南河谷到西部雪峰与黄土高原的艺术长卷。
2. atlas-camp.webp：篝火营地，人与物的夜间叙事。
3. atlas-poetry.webp：远山、云海与山口，留白适于诗词路线。
4. atlas-study.webp：行军书桌与窗外山河，学习路线的静谧终点。
历史序幕、万里征途、四路红军、长征回响复用已完成的不同主题全景与地形素材。

## 实施顺序
1. 建立共用路线数据、地图视图与 URL 规则。
2. 接入八个入口及准确内容目标，增加返回路径。
3. 生成并接入四幅全景，完善桌面和手机布局。
4. 验证八模块、节点数量、旧链接、返回原站、图片加载、手机溢出、测试和构建。

## 边界
不替换原方案完整史料，不删除原学习记录，不新增在线服务，不发布。保留既有六幕互动为可选体验。生成图是艺术演绎，并非实地 360° 影像。
