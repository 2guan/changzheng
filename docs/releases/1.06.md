# 重走长征路 V1.06

发布日期：2026年10月27日。

## 学习中心

- 重新组织六个入口：足迹与勋章、知识测验、情境体验、行军笔记、我的收藏、纪念证书。行囊备份并入行军笔记，证书独立展示。
- 知识测验保存上一次完成的成绩，支持重新答题，并保留未完成答题的进度；重新作答期间仍可查看上次成绩。
- 纪念证书支持点击放大，放大后可拖动查看；小尺寸系统标志移到“山河为证，初心如炬。”上方。
- 学习中心地图采用半透明黑色按钮、连接线和说明区渐变，选中节点保留红色。

## 诗意长征

- 六篇“写诗背景与白话解读”补充背景和赏析，不重复列出整首诗词原文，并恢复模块间距。
- 六篇诗文分别搭配《七律·长征》《遵义会议放光辉》《大会师》《四渡赤水出奇兵》《过雪山草地》《到吴起镇》，提供背景介绍、配读说明及央视欣赏入口。
- 根据用户提供文本加入六首歌曲的歌词，保留演唱中的重复句和衬词，整理分行、分段。
- 诗意长征地图的红棕色节点增加透明度。

## 配置与体验

- 默认背景音乐音量调整为20%；已有浏览器音量偏好继续保留。
- 版本信息卡片支持通过运行时环境变量 `SITE_PRODUCER`、`SITE_PRODUCER_BRANCH` 配置两行展示文字，默认显示“纪念长征胜利90周年专题”。更改后重新创建容器即可生效。
- 公开配置接口仅返回上述展示文字，不返回语音密钥等服务端配置。

## 部署

- Git 标签：`v1.06`；页面显示 V1.06；npm 版本为 `1.0.6`。
- Docker 镜像：`changzheng:1.06`，平台 `linux/amd64`，默认端口 `4061`。
- 离线部署包位于 `release/1.06/`，包含镜像压缩包、Compose 配置、环境变量示例、部署说明、版本说明和 SHA256 校验文件。镜像归档不上传 GitHub。
- 升级时保留已有 `.env.local`，替换部署配置、导入镜像后执行 `docker compose up -d --no-build --pull never --force-recreate`。
- 学习记录仍保存在访问者浏览器中；保持原来的访问域名和端口可继续使用原有记录。
