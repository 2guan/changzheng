# 重走长征路 V1.1

2026年11月10日发布。

标题栏、版本信息卡片和学习纪念证书统一采用金黄色党徽，图案取自[共产党员网发布的标准版本](https://www.12371.cn/2021/07/09/ARTI1625818075938118.shtml)。

部署时将 `public/branding/` 与 `compose.yaml` 一同复制到服务器。替换其中的 `logo.png` 后刷新页面即可使用新标志。纪念证书在下次生成时采用新图。

离线镜像为 `changzheng:1.1`，支持 Linux x86_64，默认端口为 4061。从 V1.06 升级时保留已有 `.env.local`，导入镜像后使用本版 Compose 配置重新创建容器。具体步骤见[部署说明](../docker-deployment.md)。
