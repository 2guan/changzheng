# 22站全景漫游改版

需求：把万里征途全部22站做成全景，减少互动。

- 默认进入22站连续全景，站点深链接也直接打开对应场景；资料地图保留独立模式。
- 每站独立场景图。沿用已有于都、夹金山、草地三图，新增其余19图。
- 全景采用宽幅艺术画卷，可拖动/滑块环顾，并非实地360°摄影。
- 每站两个可选观察点；概览与两段叙事；随时前后切换、直接选站；不设任务解锁、答题或资源负担。
- 默认静止阅读，可选自动漫游。专注模式、隐藏文字看景、完整史料仍可用。
- 单独保存看过的全景与上次站点；不将短暂浏览自动计为完成全文阅读。
- 原六幕互动代码和存档保留，作为学习中心可选入口。
- 验收：22张本地素材与44个细节；22站导航/深链接；断点续行；桌面/手机拖动；边界和生产构建测试。
