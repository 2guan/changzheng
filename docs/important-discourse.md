# 详情页“总书记重要论述”

## 材料与引用边界

材料来自用户提供的《总书记重要论述.md》，原件保存在 `docs/references/总书记重要论述.md`。`src/discourse-data.json` 保存十九组材料中的引文段落和文档所列出处；去除 Markdown 排版标记及最外层引号，保留正文措辞、段落、内部引号与省略号，不根据标题自行补写讲话。

第十八组的“四个伟大远征”部分混合了引语与概述，因此只采用原稿以引号明确标注的四条表述；“四条制胜之道”同样分别呈现。两组各自标示相应年份出处，不合成为一段连续讲话。

原稿部分条目将不同年份、不同场合的讲话合并列示，部分出处只有概括名称。此次保留供稿中的出处，不擅自把合并来源归为某一次讲话。已尝试检索正式来源，但未完成所有段落的逐字核验；此内容库是用户供稿的整理，不代表经过完整独立核实的讲话定本。后续校订应同时核对原文和场合、日期，保持可追溯，不静默改写引语。

## 实现

- `src/discourse.ts`：显式映射，返回材料 ID，无无关内容的兜底引文。
- `src/components/ImportantDiscourse.tsx`：统一语义化 section / blockquote / cite 组件。
- `TopicDialog` 在非故事详情上部显示；篝火夜话统一在物件图片之后、故事正文之前显示；征途 `Reader` 在标题及时间地点之后、正文摘要之前显示。继承原阅读弹窗的滚动及键盘行为。
- `src/discourse.css`：棕色双细线框、朱砂暗红正文、棕色出处，手机内收边距及字号。
- 引文正文参与详情朗读，区域标题与出处跳过，沿用全站单语音通道和独立背景音乐。
- `tests/discourse.test.ts`：验证段落均来自供稿原文、每段有出处，以及页面映射和非相关页面排除。

## 单篇选段

每个详情只展示一个完整引文区块及其出处。材料库保留其他候选段落，页面不再连续叠加。遵义会议选会议经验段、三大主力会师选将台堡考察段、红小鬼选青年战士段；赓续长征与写下回望选新时代长征路段，四重价值选长征精神定义段。其他页面保留原匹配材料的第一段。
