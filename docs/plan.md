# 重走长征路：产品与实现规划

## 产品目标

将用户提供的长征网站方案实现为八个独立页面模块，以山河、事件、人物与主动学习连接历史。2026-10-23 用户明确要求停止 engineering 技能流程，后续直接开发，不使用工程控制账本。

## 八个模块

| 模块 | 地址 | 功能 |
| --- | --- | --- |
| 启程首页 | `#/home` | 原创山川长卷、视差、站点入口与全站目录 |
| 历史序幕 | `#/prologue` | 出发背景、三维度对照、行军负重实验 |
| 万里征途 | `#/journey` | 22站地图、四路图层、HUD、全文阅读、收藏、Remotion复盘 |
| 四路红军 | `#/armies` | 四军路线、队伍档案、时间对照 |
| 篝火夜话 | `#/stories` | 20篇编辑后的主题故事、分类、搜索与阅读记录 |
| 长征回响 | `#/meaning` | 宣言书/宣传队/播种机释义、常见误解问答 |
| 诗意长征 | `#/poetry` | 五组诗词（三首小令合并）、逐句突出、赏析、设备朗读 |
| 学习中心 | `#/learn` | 足迹与收藏、4项情境任务、15题测验、错题回看、PNG证书 |

## 视觉与交互

朱砂红 #96362D、古纸黄 #F7F3E8、暖金 #AC8245。中文宋体标题与系统黑体信息；首页标题自托管 Noto Serif SC 子集。山川和行军物件画作为 AI 艺术演绎。信息页保持温暖纸色，雪山/草地地图有局部环境色。

Motion 提供入场、视差与路线绘制；Remotion Player 提供可暂停、拖动、按四次渡河跳转的24秒四渡赤水叙事。动画不自动播放，减少动态偏好下关闭界面位移动效。

## 数据与边界

静态React应用，无账号与支付，没有后端用户数据库。学习数据存于浏览器localStorage，读取时验证结构。hash路由使静态托管不依赖服务器重写。图片、字体在工程内本地托管；诗词朗读依赖设备提供的中文语音。

所有文字为策划原稿的编辑整理，而非无审校照录。历史概要、文学作品与纪念叙事明确区分。地图、行程和互动数值是教学示意。完整商业发行仍需史料与权利审校。

## 验证路径

数据与纯函数测试 → TypeScript与生产构建 → 桌面实际导航 → 手机任务与测验 → 刷新保存 → 八模块溢出检查 → 私有发布。记录见 verification.md。
