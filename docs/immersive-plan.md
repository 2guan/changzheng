# 亲历模式改版

保留八模块，把万里征途的默认入口改成连续的六幕亲历模式；资料地图由显式入口保留。已有 station / read 深链接继续打开资料页。

## 体验主线
1. 选择虚构观察身份，选三件行囊物品。身份改变提示与手记，物品影响雪山分衣与草地分食叙事。
2. 夜渡：点击河岸空间线索；推动路线滑块渡河，画面标记与灯光跟随。
3. 赤水：根据新消息选择四次行进方向，动态画出折返路线；行动后展开历史背景。
4. 雪山：拨开风雪寻找落队同伴；使用行囊或一起分担，画面从风雪转向山口。
5. 草地：探查与迈步分离，按行寻找可靠落脚点；抵岸后触发金色鱼钩的文学回声。
6. 会师：回顾自己的操作形成的手记；写信、保存、导出个人文字纪念。

## 实现与验收
- 独立本地状态并校验，断点续行，不修改旧资料阅读记录。
- 本地生成场景图，程序合成可选环境声，静音默认；隐藏页与退出时停止声音。
- 所有动作支持按钮/原生滑块键盘操作；触摸无须悬停；尊重减少动态效果。
- 教学情境/艺术演绎明确说明，不把虚构身份与操作后果表述为历史事实。
- 测试解锁与存档边界；桌面与手机完整通关；检查控制台、溢出、原有资料入口。
